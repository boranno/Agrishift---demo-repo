# AgriShift

NASA Earth-observation-informed crop suitability and crop-rotation decision support.

[AgriShift Demo](https://agrishift-demo-mnib.vercel.app/)

## Status
Initial scaffold only; planned features and models are not implemented yet.





## Architecture
- `frontend/`: web user interface
- `backend/`: API and application services
- `ml/`: data pipeline, experiments, training, evaluation, inference
- `agronomy/`: crop reference data and transparent agronomic rules
- `database/`: schema, migrations, seed data
- `docs/`: architecture, feature specifications, data documentation

See `docs/roadmap.md`.
