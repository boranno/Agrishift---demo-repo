# AgriShift Development Roadmap

1. Finalize blueprint and feature specifications.
2. Build frontend and backend foundation.
3. Implement website features with verified data or transparent rule-based logic.
4. Collect, document, clean, and validate real datasets.
5. Train and evaluate the soil salinity/EC estimation model.
6. Integrate validated predictions with crop suitability and rotation recommendations.
7. Test, document, and prepare the final demo.

Do not display fabricated predictions before a validated model is available.
